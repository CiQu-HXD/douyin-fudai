# 抖音直播间超级福袋自动抢夺助手(MuMu 模拟器版)

电脑端 Python 程序,通过 ADB 控制 MuMu 模拟器里的抖音 APP,自动检测直播间福袋、
参与抽奖、关闭结果弹窗,**中奖或未中奖都会自动继续蹲下一轮**。

> ⚠️ **风险提示**:自动参与抽奖违反抖音平台规则,存在抽奖资格受限、封禁账号的风险。
> 仅供学习交流,请自行评估风险。建议:使用小号、保持脚本默认的低频率随机延迟、
> 不要同时挂多个直播间。

---

## 工作原理

```
电脑端 Python 脚本
   │  ADB(安卓调试桥)
   ▼
MuMu 模拟器(安卓) ── 抖音 APP(开着某个直播间)
   ▲
   │ 脚本循环执行:
   │  1. 截图 → OpenCV 模板匹配找「福袋入口」图标
   │  2. 点击图标 → 弹窗出现 → 找「发弹幕参与」按钮 → 点击
   │  3. 抖音会自动预填福袋口令 → 找「发送」按钮 → 点击
   │  4. RapidOCR 识别弹窗上的开奖倒计时 → 生成「闲逛计划」
   │  5. 模拟真人(wander_mode):参与后在原直播间再停留 30~90 秒,
   │     然后上划去隔壁直播间闲逛+随机点赞;开奖前 45 秒按原路
   │     下划返回原直播间,睡到开奖时刻(OCR 识别失败则降级盲等)
   │  6. 开奖后密集检查(6 秒一次):中奖 → 记录统计+关闭;
   │     未中奖 → 关闭;继续蹲本直播间等下一轮
   │  7. 回到第 1 步,无限循环;参与/中奖次数记入 stats.json
```

利用了抖音新版特性:点弹窗里的"发弹幕参与"后,评论框会**自动预填口令**,
所以脚本不需要中文输入功能。

## 环境要求(本机已满足)

- MuMu 模拟器 12(已检测到:`D:\Program Files\Netease\MuMu`)
- Python 3.13 + opencv-python(项目自带 `.venv`,已装好)

## 使用步骤

### 第 0 步:准备模拟器

1. 启动 MuMu 模拟器,安装并登录抖音 APP(建议用小号)。
2. 模拟器**分辨率保持默认**(模板截取后,运行时分辨率必须与截取时一致,
   如果中途改了分辨率,需要重新截模板)。
3. 设置 → 开发者选项 → 确认「USB 调试」开启(大多数情况默认就是开的)。

### 第 1 步:测试连接

```bat
cd /d <项目所在目录>
.venv\Scripts\python fudai.py test
```

看到 `截图成功:1080x1920` 之类输出即正常。失败时检查模拟器是否已启动。

### 第 2 步:截取按钮模板(首次必做,约 2 分钟)

先在模拟器里**进入任意一个正在发福袋的直播间**(直播间右上角能看到金色福袋图标)。

```bat
.venv\Scripts\python fudai.py setup
```

向导会依次让你截取 6 张小图。每一步:在模拟器里摆好画面 → 回到命令行按回车 →
弹出截图 → **用鼠标拖框选目标 → 按回车确认**(ESC 跳过可选项目)。

| 顺序 | 模板 | 在哪个画面截 | 框什么 |
|---|---|---|---|
| 1 | `entry` | 直播间画面(有福袋) | 右上角/上方的金色福袋小图标(**只框袋子本身**) |
| 2 | `join_btn` | 点开福袋后的弹窗 | 「发弹幕参与」按钮(只框按钮) |
| 3 | `send_btn` | 点完参与后弹出的评论框 | 底部输入框旁的蓝色「发送」按钮 |
| 4 | `close_btn` | 福袋弹窗 | 右上角关闭 ×(或「我知道了」) |
| 5 | `win_btn`(可选) | 中奖弹窗 | 「领取」按钮(只用于日志标注中奖,**默认不点**,见 `win_action`) |
| 6 | `lose_btn`(可选) | 未中奖弹窗 | 关闭按钮 |

**中奖弹窗默认也是直接关闭**(和未中奖一样关掉继续蹲下一轮),这是默认行为;
如果想中奖后自动点「领取」,把 `config.json` 里 `"win_action"` 改成 `"claim"`。

**截模板技巧**:框得越小越准——只框按钮/图标本身,不要框到周围背景;
按钮带倒计时数字的部分不要框进去(文字一直在变,会导致匹配失败)。

`win_btn` / `lose_btn` 需要等一次真实开奖才能截;没截也不影响运行,
未中奖弹窗会由 `close_btn` 兜底关闭。

### 第 3 步:开始抢福袋

在模拟器里停在那个直播间,然后运行:

```bat
.venv\Scripts\python fudai.py run
```

日志会实时输出「蹲福袋 → 福袋弹窗 → 发弹幕 → 等开奖」的状态流转。
按 `Ctrl+C` 随时停止。

也可以不带参数运行 `python fudai.py` 进入交互菜单。

## 参数调整(config.json)

| 参数 | 默认 | 说明 |
|---|---|---|
| `match_threshold` | 0.82 | 模板匹配阈值,误点就调高,识别不到就调低到 0.75 |
| `tap_jitter` | 4 | 每次点击的随机偏移像素(拟人化) |
| `delay_min/max` | 2~5 秒 | 蹲福袋时每次截图间隔,别调太小,风控风险↑ |
| `wait_poll_min/max` | 20~40 秒 | 等开奖时轮询结果的间隔 |
| `win_action` | close | 中奖弹窗动作:`close`=直接关闭继续蹲;`claim`=点「领取」 |
| `use_ocr` | true | 用 RapidOCR 识别开奖倒计时精准等待;OCR 不可用时自动降级盲等 |
| `draw_poll_seconds` | 6 秒 | 开奖时刻后密集检查结果的间隔 |
| `switch_after_draw` | **false** | 默认固定蹲守一个直播间;true=开奖后自动切下一个 |
| `idle_switch_minutes` | **0** | 默认永不切直播间;想要"没福袋就换直播间"改成 5 之类的数值 |
| `wander_mode` | true | **模拟真人防风控**:参与后去隔壁直播间闲逛,开奖前自动返回原直播间 |
| `wander_leave_min/max` | 30~90 秒 | 参与成功后在原直播间随机停留的时长 |
| `wander_hops` | 1 | 去几家隔壁直播间(下划按原路返回,1 家最稳,建议别超过 2) |
| `return_before_seconds` | 45 秒 | 开奖前多少秒开始往回划 |
| `wander_like` | true | 闲逛时随机双击点赞,更像真人 |
| `min_stay_seconds` | 60 秒 | 每个直播间至少停留时间,防止频繁滑动触发风控 |
| `serial` | 127.0.0.1:16384 | MuMu12 默认 ADB 端口,连不上会自动试其他端口 |

## 抖音提示「设备有风险」怎么办

本机 MuMu 已做过的环境伪装(2026-11-03,改动需重启模拟器生效):

| 设置项 | 值 | 说明 |
|---|---|---|
| `root_permission` | **false** | Root 开启是风控头号特征,必须关 |
| `phone_imei` | 随机合法 IMEI | MuMu 默认 IMEI 全网共享早被标记 |
| `resolution_mode` | **phone.1**(1080x1920 竖屏) | 手机竖屏模式更像真人,别用平板/横屏 |
| `phone_brand/model` | Xiaomi 12S | MuMu 默认伪装,保持即可 |

登录排查清单(按顺序试):

1. 重启模拟器后**清除抖音数据**(设置→应用管理→抖音→清除数据)或卸载重装
   官网最新版 APK(不要用第三方渠道包)。
2. 用**手机号 + 短信验证码**登录(风控最低),登录后先正常刷几分钟视频再进直播间。
3. 确认电脑上 Clash/v2rayN 等代理**没有开 TUN/全局模式**(模拟器流量跟着走的话,
   出口变成机房 IP 必被风控)。可在模拟器浏览器搜「IP」看归属地是不是本地。
4. 换一个小号试——「设备风险」有时是账号×设备组合被标记;新注册的号先在手机上
   养几天再用。
5. 都不行就上**真机**:手机开 USB 调试连电脑,`adb devices` 拿到序列号后把
   `config.json` 的 `serial` 改成它,重新 `setup` 截模板。脚本对真机完全兼容,
   真机设备指纹真实,基本 100% 能登录。

## 常见问题

**Q:连接失败?**
确认 MuMu 已启动。脚本会自动尝试 16384 / 16416 / 7555 等常见端口;
仍失败则打开 MuMu 设置检查 ADB 调试开关。

**Q:一直"蹲福袋"没反应?**
1)福袋入口模板截得太大或框进了变化的倒计时数字 → 重新截;
2)该直播间当前真的没有福袋 → 换个正在发福袋的直播间测试;
3)阈值太高 → 降到 0.78 试试。可疑时看 `screenshots/` 里的存档截图。

**Q:卡在"没找到发送按钮"?**
你的抖音版本点参与后可能不会自动预填口令(老版本需要手动输口令)。
把 `screenshots/no_send_btn_*.png` 发给助手,可以加 ADBKeyboard 中文输入支持。

**Q:改了模拟器分辨率后全都不识别?**
模板与分辨率绑定,改分辨率后重新 `setup` 截一遍所有模板。

**Q:中奖弹窗关不掉?**
默认中奖也是找 `close_btn`(或 `lose_btn`)关闭。有些中奖弹窗没有右上角 X,
只有「开心收下」这类按钮——出现一次中奖弹窗后,看 `screenshots/WIN_*.png` 存档,
把 `close_btn` 或 `lose_btn` 模板重截成那个按钮即可;或把 `win_action` 改成 `claim`。
